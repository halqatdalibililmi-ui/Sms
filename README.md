# Academic SMS — نظام إدارة المدرسة الأكاديمي

تطبيق Flutter محلي لإدارة المدرسة، مبني على الكود المرفق في الطلب، مع دعم العربية والإنجليزية، الوضعين الفاتح والداكن، وقاعدة بيانات SQLite محلية.

## الوظائف الموجودة

- تسجيل الدخول مع تشفير كلمات المرور باستخدام salt وSHA-256 وتسجيل العمليات.
- أدوار المستخدمين: مدير، معلم، طالب، وولي أمر.
- لوحة تحكم إحصائية للطلاب والمعلمين والحضور والرسوم.
- إدارة الطلاب مع الصورة والبيانات الشخصية والصف والشعبة وولي الأمر.
- إدارة المعلمين والصفوف والشعب والمواد.
- تسجيل الحضور بالحالات: حاضر، غائب، متأخر، بعذر، وخروج مبكر.
- إنشاء الامتحانات وإدخال الدرجات وحساب المؤشرات.
- الرسوم والمدفوعات والإيصالات.
- بطاقات الطلاب والمعلمين، الشهادات، وكشوف الدرجات بصيغة PDF والطباعة.
- التقارير وسجل العمليات التدقيقي Audit Log.
- إعدادات المدرسة: الاسم، الشعار، العنوان، الهاتف، اللون، اللغة، والمظهر.
- بيانات تجريبية جاهزة للاختبار من شاشة الإعدادات.

عند أول دخول للحسابين الافتراضيين سيطلب التطبيق تغيير كلمة المرور.

## التشغيل والبناء

1. ثبّت Flutter 3.x أو أحدث مع Android SDK.
2. نفّذ داخل مجلد المشروع:

```bash
flutter pub get
flutter run
flutter build apk --release
```

ملف APK الناتج سيكون عادةً في:

```text
build/app/outputs/flutter-apk/app-release.apk
```

## ملاحظة التحقق

تم تجهيز `pubspec.yaml` و`lib/main.dart` وفحص سلامة الأقواس والبنية النصية ووجود الأصناف الرئيسية. بيئة التنفيذ الحالية لا تحتوي على Flutter أو Dart أو Android SDK، لذلك لم يكن ممكنًا تشغيل `flutter pub get` أو إنتاج APK داخل هذه الجلسة. المشروع جاهز للنقل إلى جهاز تطوير Flutter لإكمال البناء مباشرة.
